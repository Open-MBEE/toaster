## What was scanned

The published page set is `myst.yml`'s toc: 59 pages (6 `docs/` pages, the case study, and 10 chapters of index, notebooks and conclusion). For each page the scan reads, as a reader sees them: markdown prose, table rows and fenced blocks; the full source of every code cell (comments, string literals and code, because readers see source); and the stored output text of every code cell (image outputs skipped). There were 726 notebook cells, 172 with stored outputs, and 751 output lines. HTML comments in a `.md` file are scanned too (they are not rendered, one occurrence, KEEP).

Conventions in the table: wrapped lines in a `.md` paragraph are joined with a single space; `⏎` marks a line break between lines of one code cell or output that are quoted together; a bare `|` inside a quote is escaped. Every quoted sentence was checked as a verbatim substring of its file (the script aborts otherwise). The locator is the line number in a `.md` file (`L12`), or `cell-id Lp` (paragraph starting at line p of a markdown cell), or `cell-id code line n` / `output line n` for code cells. ## Classification rules applied

- **LINK**: the reader benefits from the full text and the file exists at `main` (checked below). Deferred-gap entries (`DEFERRED.md D-nnn`) get the per-entry anchor; issue numbers get the issue URL; `exercises/`, `models/` (in prose and Python comments), `src/`, `scripts/`, `tests/`, `glossary/`, `.github/` paths and bare repo file names get the blob URL (tree URL for directories).
- **REWORD**: process jargon with no value to a stranger (`SA-7`, `DL-nnn`, `AGENTS.md 1.6`, skill names, work-contract ids, commit hashes GitHub does not have, "round of work", "retrofit", "Pattern B"), and published pages referenced by repo path in code font (made into in-site links). The proposed text keeps the sentence's meaning and stands alone.
- **KEEP**: commands the reader runs in a clone (`uv ...`, `npm ...`, fenced blocks), `docs/contributor.md` describing how the project works, the functional code paths including `models/` paths on executable lines (A6, orchestrator ruling (a)), D-nnn ids inside SysML doc comments and ReviewRecord strings (A7, ruling (b)), scratch file names the cell itself writes, and narrative on the case-study page (A3).

## Scan script

`a4_scan.py`, run from the repository root as `python3 a4_scan.py candidates.json`; it needs only the standard library and PyYAML (both present in the project environment). It produced 434 candidates on this branch (427 under the first set of patterns; adding `chapters/` to the repo-path pattern and `index.md` as a page-name pattern after review added the other 7), merged into the 365 rows below: code and output lines of one cell, one type and one kind (Python comment, or string / executable line) become one row, a link target already reported under its path type is not repeated, and an executable `models/` line already reported as a code path is not repeated. Classification is by the rules above plus hand-written replacement text for every REWORD row; that text is in the table, not in the script.

````python
#!/usr/bin/env python3
"""PA-4 scan: every reader-visible reference to something that will not exist on the site.

Run from the repository root:  python3 a4_scan.py candidates.json
Reads myst.yml's toc; for each published page scans markdown prose, tables, fenced blocks,
code-cell source (comments, strings, code) and stored output text (images skipped).
Emits one candidate per (unit, artifact type); classification is a separate step.
"""
import json, os, re, sys, yaml

# ---- 1. the published page set ------------------------------------------------------------
def toc_files():
    out = []
    def walk(ns):
        for n in ns:
            if "file" in n:
                out.append(n["file"])
            walk(n.get("children", []))
    walk(yaml.safe_load(open("myst.yml"))["project"]["toc"])
    return out

PAGES = []
for base in toc_files():
    PAGES.append(base + (".md" if os.path.exists(base + ".md") else ".ipynb"))
PAGESET = set(PAGES)

# ---- 2. artifact types ---------------------------------------------------------------------
SKILLS = sorted(os.listdir(".claude/skills")) + ["layer-auditor", "simulated-learner"]
TYPES = [  # (type name, regex)
    ("DEFERRED.md entry",    r"\bD-\d{3}\b|\bDEFERRED(?:\.md)?\b"),
    ("decisions/log.md entry", r"\bDL-\d+\b"),
    ("decisions/ path",      r"\bdecisions/[\w./*{}-]*"),
    ("AGENTS.md",            r"\bAGENTS(?:\.md)?\b"),
    ("CLAUDE.md",            r"\bCLAUDE(?:\.md)?\b"),
    (".claude/ skill or agent", r"\.claude/[\w./-]*|\b(?:" + "|".join(map(re.escape, SKILLS)) + r")\b|\bskills?\b"),
    ("SA-n standing assumption", r"\bSA-\d+\b"),
    ("work-contract id",     r"\bwork contract [A-Z0-9-]+|\bPASS\d+-\d+\b|\bCH\d\d-[A-Z-]+\b|\b(?:this|the reconciliation) contract\b"),
    ("issue number",         r"\b(?:toaster|OpenSysML)#\d+"),
    ("exercises/ path",      r"\bexercises/[\w./{}-]*"),
    ("models/ path",         r"\bmodels/[\w./-]*"),
    ("other repo path",      r"(?<![\w/.:-])(?:src|scripts|tests|glossary|docs|chapters|\.github)/[\w./*{}:-]*"),
    ("repo file name",       r"(?<![\w/.-])(?:[\w-]+\.(?:py|toml|lock|yml|sysml|json)|\.nvmrc)\b"),
    ("repo command",         r"\b(?:uv (?:run|sync|lock)|npm (?:ci|install)|npx|pytest|git clone)\b"),
    ("page named by file name", r"(?<![\w/.-])index\.md\b"),
    ("commit hash",          r"`[0-9a-f]{7,40}`"),
    ("process jargon",       r"\bworktree\b|\bPattern B\b|\bapproved by Z\b|\bZ(?:'s| reconsidered| set| was)\b|\bharness\b|\bround of work\b|\bdiffersFrom\b|\bretrofit\b|\(chat,|\bbuilt this session\b|\breviewer\b|\bagents?\b|\borchestrator\b"),
]
TYPES = [(n, re.compile(p)) for n, p in TYPES]
CODE_TYPES = [  # extra, code cells only: machine paths a reader sees in source
    ("code path (functional)", re.compile(r"""Path\((?:"|')(?:\.\./)+[\w./-]+(?:"|')\)|Path\.home\(\)\s*/\s*"[^"]+"|Path\("/opt/[^"]+"\)|SCRATCH_DIR\s*=\s*Path\("[^"]+"\)""")),
]

LINK = re.compile(r"(!?)\[([^\]]*)\]\(([^)\s]+)\)")
def neutralise(page, text):
    """Links to published pages / anchors / existing images resolve on the site: drop their target."""
    def sub(m):
        bang, label, target = m.groups()
        if re.match(r"(https?://|mailto:|#)", target):
            return m.group(0)
        t = os.path.normpath(os.path.join(os.path.dirname(page), target.split("#")[0]))
        return f"[{label}]" if (t in PAGESET or (bang and os.path.exists(t))) else m.group(0)
    return LINK.sub(sub, text)

def unresolved_links(page, text):
    out = []
    for m in LINK.finditer(text):
        target = m.group(3)
        if re.match(r"(https?://|mailto:|#)", target):
            continue
        t = os.path.normpath(os.path.join(os.path.dirname(page), target.split("#")[0]))
        if t not in PAGESET and not (m.group(1) and os.path.exists(t)):
            out.append(target)
    return out

# ---- 3. units of reader-visible text ------------------------------------------------------
def md_units(page, text, cell=None):
    """(loc, kind, text): paragraphs (sentence-split later), table rows, fenced lines."""
    prefix = f"{cell}:" if cell else ""
    para, start, fence = [], None, False
    def flush():
        nonlocal para, start
        if para:
            yield (f"{prefix}L{start}", "prose", " ".join(s.strip() for s in para))
        para, start = [], None
    for i, line in enumerate(text.split("\n"), 1):
        if line.strip().startswith("```"):
            yield from flush(); fence = not fence; continue
        if fence:
            if line.strip():
                yield (f"{prefix}L{i}", "fence", line.strip())
        elif not line.strip():
            yield from flush()
        elif line.lstrip().startswith("|"):
            yield from flush(); yield (f"{prefix}L{i}", "table", line.strip())
        else:
            if re.match(r"\s*([-*]|\d+\.)\s|\*\*[A-Z][\w ]*:\*\*", line):   # list item / bold label starts a unit
                yield from flush()
            if not para: start = i
            para.append(line)
    yield from flush()

def units():
    for page in PAGES:
        if page.endswith(".md"):
            for loc, kind, t in md_units(page, open(page, encoding="utf-8").read()):
                yield page, loc, kind, t
        else:
            for c in json.load(open(page, encoding="utf-8"))["cells"]:
                cid, src = c.get("id", "?"), "".join(c["source"])
                if c["cell_type"] == "markdown":
                    for loc, kind, t in md_units(page, src, cid):
                        yield page, loc, kind, t
                else:
                    for j, line in enumerate(src.split("\n"), 1):
                        yield page, f"{cid}:src{j}", "code", line.rstrip()
                    for o in c.get("outputs", []):
                        txt = "".join(o.get("text", []))
                        for mt, v in o.get("data", {}).items():
                            if not mt.startswith("image/"):
                                txt += "".join(v) if isinstance(v, list) else str(v)
                        if o.get("output_type") == "error":
                            txt += "\n".join(o.get("traceback", []))
                        for j, line in enumerate(txt.split("\n"), 1):
                            yield page, f"{cid}:out{j}", "out", line.rstrip()

SENT = re.compile(r"(?<=[.!?])(\*\*|\*|\)|\"|')?\s+(?=[A-Z`\[*\"'(])")
def sentences(text):
    """Split on sentence ends; a closing ** ) \" stays with the sentence it closes."""
    out, pos = [], 0
    for m in SENT.finditer(text):
        out.append(text[pos:m.start()] + (m.group(1) or ""))
        pos = m.end()
    out.append(text[pos:])
    return [s for s in out if s.strip()]

def types_in(page, kind, text):
    scan = neutralise(page, text) if kind in ("prose", "table", "fence") else text
    found = {}
    for name, rx in TYPES + (CODE_TYPES if kind in ("code", "out") else []):
        toks = [m.group(0) for m in rx.finditer(scan)]
        if toks:
            found[name] = toks
    if kind in ("prose", "table"):
        ul = unresolved_links(page, text)
        if ul:
            found["unpublished link target"] = ul
    return found

def main(outpath):
    cands = []
    for page, loc, kind, text in units():
        # prose is judged sentence by sentence; table rows, fenced and code lines whole
        parts = sentences(text) if (kind == "prose" or len(text) > 220) else [text]
        for s in parts:
            for tname, toks in types_in(page, kind, s).items():
                cands.append({"file": page, "loc": loc, "kind": kind, "quote": s.strip(),
                              "type": tname, "tokens": toks})
    # exactness: every quoted sentence is a substring of the file text (whitespace-collapsed)
    squash = lambda t: re.sub(r"\s+", " ", t)
    for page in PAGES:
        blob = open(page, encoding="utf-8").read()
        if page.endswith(".ipynb"):
            nb = json.load(open(page))
            blob = "\n".join("".join(c["source"]) + "\n" + json.dumps(c.get("outputs", []), ensure_ascii=False)
                             for c in nb["cells"])
            blob += "\n" + json.dumps(blob)  # JSON-escaped form for strings inside outputs
        pb = squash(blob)
        for c in (c for c in cands if c["file"] == page):
            q = squash(c["quote"])
            if q not in pb and q.replace("\\", "") not in pb.replace("\\", ""):
                raise SystemExit(f"NOT VERBATIM: {page} {c['loc']}: {q[:80]}")
    json.dump(cands, open(outpath, "w"), indent=1, ensure_ascii=False)
    print(len(PAGES), "pages;", len(cands), "candidates")

if __name__ == "__main__":
    main(sys.argv[1])
